\section{Introducción}

\subsection{Especificaciones del Proyecto}

El presente informe corresponde al proyecto final de la asignatura \textbf{Introducción a la Matemática de Seguros}, desarrollado durante noviembre y diciembre de 2020.

\begin{hallazgobox}
\textbf{Parámetros Asignados:}
\begin{itemize}
    \item \textbf{Tabla de Referencia:} INVALIDEZ 2014 - Masculino
    \item \textbf{Criterios de Selección:} Origen = 2, Sexo = Masculino
    \item \textbf{Período de Análisis:} 01/01/2000 -- 31/12/2012
    \item \textbf{Tasa de Interés Técnico:} 5\% anual
    \item \textbf{Raíz de la Tabla:} $l_{10} = 10.000.000$
\end{itemize}
\end{hallazgobox}

\subsection{Estructura del Trabajo}

El proyecto se divide en tres componentes con sus respectivas ponderaciones:

\begin{enumerate}
    \item \textbf{Construcción de Tabla de Mortalidad (60\%):} Obtención del cuerpo mediante graduación, evaluación de bondad de ajuste, extrapolación de cabeza y cola, y construcción de tabla completa con esperanzas de vida.
    
    \item \textbf{Valores de Conmutación (10\%):} Cálculo de funciones $D_x$, $N_x$, $S_x$, $C_x$, $M_x$ y $R_x$ para tabla obtenida y tabla de referencia.
    
    \item \textbf{Cálculo de Valores Actuales (30\%):} Cálculo y comparación de valores actuales para cinco productos actuariales utilizando ambas tablas.
\end{enumerate}

\subsection{Herramientas y Metodología}

El análisis se desarrolló utilizando \textbf{R} con las siguientes librerías principales:
\begin{itemize}
    \item \texttt{tidyverse}, \texttt{lubridate} — Manipulación de datos
    \item \texttt{MortalityTables} — Graduación y tablas de mortalidad
    \item \texttt{MortalityLaws} — Extrapolación (Oppermann y Heligman-Pollard)
    \item \texttt{randtests}, \texttt{BSDA}, \texttt{tseries} — Tests estadísticos
\end{itemize}

\textbf{Script principal:} \texttt{trabajo\_final.r}
